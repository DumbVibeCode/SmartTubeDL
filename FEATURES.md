# SmartTubeDL — что умеет программа

## YouTube
- Скачивание видео по ссылке (1080p / 720p / 480p / MP3)
- Поддержка возрастных ограничений (18+) — автоматически берёт куки из Firefox
- Обход проблемных каналов через android-клиент YouTube
- Плейлисты и каналы — окно выбора конкретных видео
- Очередь загрузок с паузой и возобновлением
- История загрузок

## ВКонтакте (окно «Поиск музыки и видео»)
**Музыка:**
- Поиск треков по названию / исполнителю
- Загрузка аудиозаписей профиля: `vk.com/id123` или `vk.com/club123`
- Прямая ссылка на аудио: `vk.com/audios-12345`
- Треки из поста стены: `vk.com/wall-12345_67890`
- Скачивание выбранных треков в папку загрузок
- Фильтрация и сортировка результатов, история

**Видео:**
- Загрузка страницы видео: `vk.com/video/@id...` или `vkvideo.ru/@...`
- Таблица с превью, названием, длительностью
- Контекстное меню: описание видео, скачать, копировать ссылку
- Скачивание через yt-dlp

## Mail.ru
- Плейлисты: `my.mail.ru/music/playlists/...`
- Показывает список треков с исполнителем, названием, длительностью, именем владельца
- Скачивание выбранных треков

## Неизвестный Гений
- Страница произведений пользователя: `neizvestniy-geniy.ru/users/N/works/`
- Показывает список MP3-файлов с названиями
- Скачивание выбранных

## Интерфейс
- Иконка в трее, скрытие в трей при закрытии
- Прогресс загрузки на иконке трея
- Автоматическое определение типа ссылки при вставке из буфера обмена
- Окно очереди: список всех активных загрузок (YouTube + ВК)
- Настройки: папка загрузок, формат, качество видео

## Зависимости (нужно установить отдельно)
- `yt-dlp` + `yt-dlp-ejs` — для YouTube
- `Node.js` — для решения YouTube n-challenge
- `Firefox` (с аккаунтом YouTube) — для скачивания 18+ видео
- `ffmpeg` — для конвертации в MP3
- Chrome + Selenium — для поиска и скачивания ВКонтакте
